# 歌语 UtaYomi

从喜欢的歌词和短文入手学日语的自学工具。

**在线使用：https://utayomi.app**

## 这是什么

我学日语时卡在一个很具体的地方：汉字大概能猜出意思，假名读音过两天就认错；
别人的联想口诀我也记不住。所以我给自己做了这个工具：

- 🎵 **歌词学习**：网易云搜歌导入，逐句拆解（读音、词义、语法、为什么这样写），可以只学副歌
- 📖 **阅读板块**：粘贴任何日语材料逐句解析，或按你的词汇量生成小故事
- 🃏 **FSRS 复习**：看懂的词一键进复习库，按遗忘曲线排期，第二天逼你主动回忆
- あ **假名板块**：联想口诀可以对话改成你自己的版本，配笔顺动画
